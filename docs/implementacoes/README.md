# Implementações e atualizações

Esta pasta concentra os planos oficiais de evolução do sistema.

## Documento base atual

- `mvp-01-profissional-multi-paroquia.md`: visão do MVP profissional, segurança, multi-paróquia e administração global.
- `mvp-01-backlog.md`: backlog incremental com fases, critérios de aceite e entregáveis.

## Regra de uso

- Toda implementação nova deve referenciar estes documentos antes de alterar fluxo, schema, permissões ou UX.
- Se uma decisão mudar, atualizar primeiro os documentos desta pasta e depois o código.
- Em caso de conflito, priorizar:
  1. `docs/diretrizes/*`
  2. `docs/DATABASE.md`
  3. documento base do ciclo atual (`mvp-01-*`)
